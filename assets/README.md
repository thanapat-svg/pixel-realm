# assets/ — ที่วางไฟล์ภาพ/เสียงคุณภาพสูง (ไม่บังคับ)

เกมนี้เล่นได้โดยไม่ต้องมีไฟล์ในโฟลเดอร์นี้ (สไปรต์วาดด้วยโค้ด เสียงสังเคราะห์ด้วยโค้ด)
ถ้าวางไฟล์ตามชื่อด้านล่าง เกมจะโหลดมาใช้แทนของเดิมตอนเริ่มเกม — ไฟล์ที่ไม่มีจะถูกข้าม

รองรับ `.ogg` และ `.wav`

| `sfx_lvl` `sfx_upgrade` `sfx_quest` `sfx_craft` | เลเวลอัป · อัปเกรด · เควสต์ · คราฟต์ |

## ภาพ `assets/sprites/`
รองรับ `.png` (พื้นหลังโปร่งใสได้) — ภาพจะถูกย่อ/ขยายให้เท่าขนาดสไปรต์เดิมอัตโนมัติ
(ไทล์ 16×16, ไอคอน 8×8, วัตถุตามขนาดเดิม ส่วนใหญ่ 16×16)
| ไฟล์ | แทนที่ |
|---|---|
| `tile_<id>.png` | ไทล์พื้น id ตาม `TN` ใน `src/main.rs` (3 = ทุ่งหญ้า, 11 = ดินไถ, 13 = พื้นถ้ำ ฯลฯ) |
| `obj_<id>.png` | วัตถุ id ตามตารางใน `src/main.rs` (1 ต้นไม้ … 26 หม้อ, 27–32 พืช, 33 เตียง, 34 โต๊ะขั้นสูง, 36 ปากถ้ำ) |
| `icon_<n>.png` | ไอคอนลำดับที่ n (0–24 = ไอเทมตามดัชนี, 25+ = ดาบ/ธนู/คทา/เกราะ/สิ่งก่อสร้าง) |

ข้อจำกัดที่ยังไม่ได้ทำ: ภาพความละเอียดสูงจะถูกย่อลงมาเท่าสไปรต์พิกเซลเดิม (ตัวเกมเรนเดอร์แบบพิกเซลอาร์ต)
สไปรต์ผู้เล่น/ศัตรู/บอส/โปรเจกไทล์ยังเป็นภาพจากโค้ด (ยังไม่มีจุดแทนที่)

## Android
`Cargo.toml` ตั้ง `assets = "assets"` ไว้แล้ว ไฟล์ในโฟลเดอร์นี้จะถูกแพ็กเข้า APK

## v6: เตรียม asset อัตโนมัติ (tools/)
`tools/prepare_assets.sh` (รันใน GitHub Actions ก่อน build ทุกครั้ง) ทำสองอย่าง
- `tools/gen_audio.py` สร้างเพลงสเตอริโอ 6 เพลง (bgm_0 กลางวัน · 1 ค่าย · 2 บอส · 3 กลางคืน · 4 ถ้ำ · 5 เมนู) ยาว ~2:15–2:40 + sfx 27 ไฟล์ ลง `assets/audio/` (WAV 22.05 kHz 16-bit ≈ 76 MB)
- `tools/fetch_sprites.py` โหลดสเปรดชีต CC0 (Kenney Micro Roguelike 8x8) แล้วตัดช่องตาม `tools/sprite_map.json` ลง `assets/sprites/` (ต้นไม้ + ไอคอนดาบ/ธนู/ประตู)
ไฟล์ที่สร้างอยู่ใน .gitignore (สร้างใหม่ทุก build) · เกมโหลดเพลงทีละเพลง (BgmMgr) · ถ้าไม่มีไฟล์ จะใช้ chiptune ในโค้ดแทน
