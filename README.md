# Pixel Realm (Rust)

เกม open world 2D pixel เขียนด้วย Rust + [macroquad](https://macroquad.rs)
โลกสุ่มไม่มีขอบ · ตัดไม้ ขุดหิน คราฟต์อาวุธ · กลางวัน/กลางคืน · ศัตรูยามค่ำคืน · กองไฟ · แผนที่ · เซฟอัตโนมัติ

**v2 เพิ่ม:** สร้างฐาน (กำแพง/ประตู/กล่องเก็บของ) · บอสประจำไบโอม · ธนู/คทาเวทมนตร์ + ชุดเกราะ · แคมป์พ่อค้าและระบบใช้เหรียญ

## รันบนคอมพิวเตอร์

```bash
cargo run --release
```

- **Windows / macOS**: ไม่ต้องติดตั้งอะไรเพิ่ม
- **Linux** (Debian/Ubuntu): `sudo apt install libasound2-dev libx11-dev libxi-dev libgl1-mesa-dev`

## Build เป็น Android APK

ใช้ Docker image ของ cargo-quad-apk (ง่ายที่สุด ไม่ต้องลง SDK/NDK เอง):

```bash
docker run --rm -v $(pwd):/root/src -w /root/src notfl3/cargo-apk cargo quad-apk build --release
```

ได้ไฟล์ที่ `target/android-artifacts/release/apk/pixel_realm.apk`
ติดตั้งด้วย `adb install -r target/android-artifacts/release/apk/pixel_realm.apk`

> ตั้งค่า Android อยู่ใน `[package.metadata.android]` ของ `Cargo.toml` (จอแนวนอน, เต็มจอ, arm64)
> ไฟล์เซฟบน Android อยู่ที่ `/data/data/rust.pixel_realm/files/save.txt` — ถ้าเปลี่ยนชื่อ package ให้แก้ `save_path()` ใน `main.rs` ด้วย

## ฟีเจอร์ v2

**สร้างฐาน** — เมนู "สร้าง": กำแพงไม้ (ไม้ 2) · กำแพงหิน (หิน 3) · ประตู (ไม้ 4) · กล่องเก็บของ (ไม้ 8 + หิน 2) เลือกแล้วหันหน้าไปทางที่ต้องการแล้วกด R
ตีเพื่อรื้อ (ได้ของคืนบางส่วน) · กล่องที่ยังมีของอยู่รื้อไม่ได้ · เนื้อหาในกล่องทุกใบถูกบันทึกลงไฟล์เซฟ

**บอส** — สุ่มเกิดเมื่อเดินลึกเข้าไปในไบโอม (ไกลจากขอบ) ครั้งละหนึ่งตัว หลังปราบแล้วมีคูลดาวน์
- **ราชาสไลม์** (ป่าทึบ): กระโดดกระแทกพร้อมวงเตือน + เรียกลูกสไลม์ · พ่นเมือก 3 ทิศ
- **โกเลมหินยักษ์** (เขตหินผา/ภูเขา): ขว้างก้อนหิน · กระทืบพื้นเป็นวงพร้อมเศษหินกระจาย · พุ่งชนตามแนวเส้นเตือน
- เลือดต่ำกว่าครึ่ง = เฟส 2 (ตีถี่ขึ้น มีลูกเยอะขึ้น)
- ดรอป **เจลราชาสไลม์ / แกนโกเลม** ใช้คราฟต์ของระดับสูงสุดคู่กับพิมพ์เขียวจากพ่อค้า

**อาวุธระยะไกล + ชุดเกราะ** — ธนู (ไม้ 10, ลูกธนูคราฟต์จากไม้+หิน) · คทาเวทมนตร์ (อัญมณี 5 + ไม้ 4, ไม่ใช้กระสุน) · คทาราชาสไลม์ยิง 3 ทิศ
เกราะ 3 ช่อง (หมวก/เกราะอก/รองเท้า) 3 ระดับ (หิน → อัญมณี → ราชา/โกเลม) ลดดาเมจรวมสูงสุด 54% และเพิ่มความเร็วเดินสูงสุด +22%

**พ่อค้า** — แคมป์เล็กๆ สุ่มตามโลก (เต็นท์ 2 หลัง + พ่อค้า, ศัตรูไม่เกิดรอบๆ) เมื่อเดินเข้าใกล้จะ "ค้นพบ" และขึ้น **M** บนแผนที่ (เก็บในเซฟ)
ซื้อยาฟื้นฟู · ลูกธนู · พิมพ์เขียวเกราะ/อาวุธหายาก (ซื้อได้ครั้งเดียว) ด้วยเหรียญที่ดรอปจากมอนสเตอร์

## ฟีเจอร์ v3

- **เสียง 8-bit สังเคราะห์** (`audio.rs`): SFX ครบชุด + เพลงประกอบ 4 แบบที่เปลี่ยนตามฉาก (สำรวจ · แคมป์ · บอส · ดันเจี้ยน/กลางคืน) เปิด/ปิดได้ในเมนู "ตั้งค่า" (O)
- **คอมแบต**: ปุ่มพุ่ง (Shift/K, มือถือปุ่ม "พุ่ง") คูลดาวน์ 1 วิ อมตะชั่วครู่ มีเงาลากตาม · เล็งอัตโนมัติ (ปิดได้) · เลขดาเมจลอย/คริติคอล · ศัตรูกะพริบขาวและกระเด็น · จอสั่นเมื่อคริ/บอสโจมตี
- **ดันเจี้ยนลับ** (`dungeon.rs`): ทางเข้าซ่อนตามไบโอม (ขึ้น D บนแผนที่) · ห้องมินิบอส กับดักหนาม/ไฟ หีบหายาก
- **กลางวัน-กลางคืน/ฝน**: กลางคืนมีมอนราตรีแกร่งดรอป "เศษดาว" · คบเพลิงวางในฐานได้
- **RPG**: EXP/เลเวล ได้ 2 แต้มต่อเลเวล (P) เพิ่ม HP/ATK/ความเร็ว/คริ · **ทั่งตีบวก** +1..+5 (ออร่าอาวุธเปลี่ยนสี)
- **เควสต์ย่อย + ผู้ติดตาม** (หมาป่า/อัศวินจิ๋ว เก็บของดรอปให้) ที่ร้านพ่อค้า
- **UI**: แถบ HP บอสใหญ่ด้านบน · มินิแมพมุมขวาบนแสดงฐาน แคมป์ ดันเจี้ยน บอส

## ฟีเจอร์ v4 (ส่วนที่ 1)

- **เสาวาร์ป**: มีกระจายตามไบโอม เดินเข้าใกล้เพื่อปลดล็อก เปิดแผนที่ (M) แล้วแตะ **W** เพื่อวาร์ป (**บ** = กลับจุดเกิด) · วาร์ปในดันเจี้ยนไม่ได้
- **หม้อทำอาหาร** (สร้างในเมนู B): วัตถุดิบดรอปจากมอน (ค้างคาว=เนื้อ, สไลม์=เห็ด, โครงกระดูก=สมุนไพร) ทำสเต็ก (ฟื้น HP) · ซุปเห็ด (วิ่งเร็ว +25%) · ชาสมุนไพร (คริ +20%) บัฟ 2 นาที · ปรุงยาฟื้นฟู · กินจากแท็บ "ชุด/ของ" หรือกดเลข 1/2/3

## ฟีเจอร์ v4 (ส่วนที่ 2)

- **คทาธาตุ**: ไฟ (ติดเผาไหม้), น้ำแข็ง (เดินช้า), สายฟ้า (30% สตัน; บอสโดนดาเมจเพิ่ม) · ไฟเป็นธาตุเริ่มต้น ปลดล็อกน้ำแข็ง/สายฟ้าด้วยสูตรในเมนูคราฟต์ · กด Tab ตอนถือคทาเพื่อสลับธาตุ (หรือเลือกในแท็บ "ชุด/ของ") · บอสถูกเผา/ช้าได้ แต่ไฟไม่ฆ่าบอส
- **ตกปลา**: คราฟต์ "คันเบ็ด" แล้วหันหน้าเข้าน้ำกด Q / "ใช้" รอปลากิน (ขึ้น "!") แล้วกดอีกครั้งภายใน 1 วินาที · จุดน้ำเป็นระลอก = จุดพิเศษ ติดไวและมีโอกาสได้อัญมณี/เหรียญ · ปลาเอาไปย่าง (หม้อทำอาหาร) หรือขายที่พ่อค้า 7 เหรียญ/ตัว
- **ปุ่มสัมผัสโปร่งแสง 50%** · **เขตปลอดภัย**: คบเพลิงที่วางเองเป็น Safe Zone รัศมี ~5 ไทล์ มอนไม่เกิดและถูกผลักออก (บอสไม่ได้รับผล)

## ฟีเจอร์ v5

**ฟาร์ม** — เมนูสร้าง (B) → "ไถดิน" วางบนทุ่งหญ้า/ป่าเพื่อทำแปลง (วางซ้ำ = คืนหญ้า, ไม่เสียของ) · คราฟต์ "บัวรดน้ำ" (จุ 8 ครั้ง เติมโดยหันหน้าหาน้ำแล้วกด Q) · หันหน้าหาแปลงกด Q (ปุ่ม "ใช้" บนมือถือ): ปลูก → รดน้ำ → เก็บเกี่ยว · พืชโตเฉพาะตอน "ดินเปียก" (รดน้ำค้างได้ ~90 วินาที / ฝนทำให้เปียกเอง) · ข้าวโพด (60 วิ) · แครอท (42 วิ) · เมล็ดซื้อที่พ่อค้า (ตัวละ 2 เหรียญ) หรือดรอปจากสไลม์ 12% และได้เมล็ดคืนตอนเก็บ · กินพืชฟื้นเลือด (กระเป๋า → กิน) หรือขายที่พ่อค้า · เลือกชนิดเมล็ดที่จะปลูกได้ในแท็บ ชุด/ของ
**เตียงนอน** (obj 33) — กด Q ตอน 18:00–05:00 → ข้ามไปเช้า ฟื้นเลือดเต็ม ไล่มอนสเตอร์ รีเซ็ตฝน พืชที่เปียกอยู่โตเพิ่ม · เตียงที่ใช้ล่าสุดเป็นจุดเกิดใหม่เมื่อหมดสติ (ถ้าเตียงพังกลับจุดเกิดเดิม)
**โต๊ะคราฟต์ขั้นสูง** (obj 34) — แท็บ "โต๊ะขั้นสูง": ดาบคริสตัลดาว (ดาเมจ 12) · คทาดวงดาว (ยิง 5 ทิศ) · เกราะดาวตก 3 ชิ้น (ลด 25%) — ต้องมีของขั้นก่อนหน้า (ดาบแกนโกเลม / คทาราชาสไลม์ / เกราะระดับ 3) ใช้เศษดาว แกนโกเลม เจล อัญมณี
**Grid Snap** — ในโหมดสร้างมีเส้นกริดรอบตัว (เฉพาะช่องที่อยู่ในระยะ ~4.5 ไทล์) และช่องที่เลือกขึ้นกรอบเขียว/แดง · คอม: ขยับเมาส์เลือกช่อง คลิกซ้ายวาง (โจมตีใช้ Space/J) · มือถือ: แตะพื้นฝั่งขวาเพื่อเลือกช่อง แล้วกดปุ่มสร้าง · เดินห่างเกิน ~1 ไทล์เคอร์เซอร์หาย กลับไปวางหน้าตัวเหมือนเดิม
**สภาพอากาศตามไบโอม** — ดินแดนหิมะ = หิมะ (เดินช้าลงสูงสุด 18%) · ทะเลทราย = ไม่มีฝน · ที่อื่น = ฝน (ช้าลง 5%)
**แสงไดนามิก** — คบเพลิง/กองไฟ/หม้อ/เสาวาร์ป/ลูกเวทมีรัศมีแสง "หายใจ" เข้าออกนุ่มๆ (ไฟมีประกายเพิ่ม) · ถือคทาตอนกลางคืนมีแสงรอบตัวกว้างกว่า เต้นตามจังหวะ และเรืองสีตามธาตุ
**ถ้ำใต้ดิน** — ปากถ้ำ (obj 36) สุ่มแทนดันเจี้ยนห้องประมาณ 45% ของทางเข้าทั้งหมด (ยังขึ้นเป็น D บนแผนที่) · สร้างถ้ำด้วย cellular automata (สุ่มกำแพง 46% + เกลี่ย 4 รอบ + เก็บโพรงใหญ่สุด) · มืดกว่า (0.8 เทียบ 0.62) · แร่/หินตามผนังขุดได้ด้วยดาบ (แร่ให้อัญมณี + โอกาสเศษดาว) · หีบหายาก 2 ใบ + หีบมินิบอส · มอนสเตอร์หนาแน่น เลือด/ดาเมจ x1.4 และ 40% เป็นแบบ "ดุ" (เวอร์ชันกลางคืน)
**Asset placeholder** — โฟลเดอร์ `assets/audio` และ `assets/sprites` + `src/assets.rs`: วางไฟล์ `sfx_<ชื่อ>.ogg|wav`, `bgm_<n>`, `tile_<id>.png`, `obj_<id>.png`, `icon_<n>.png` เกมจะใช้แทนของที่สร้างด้วยโค้ดอัตโนมัติ (ดู `assets/README.md`) — สไปรต์ผู้เล่น/ศัตรู/บอสยังไม่มีจุดแทนที่

## โครงสร้างโค้ด

`main.rs` (โลก, ผู้เล่น, เซฟ/โหลด, วาด, อินพุต/ปุ่มสัมผัส) + โมดูล `art.rs` (สไปรต์ใหม่) · `combat.rs` (โปรเจกไทล์, เกราะ, สูตรคราฟต์) · `boss.rs` · `base.rs` (สิ่งปลูกสร้าง/โต้ตอบ) · `camp.rs` (แคมป์+ร้านค้า) · `menu.rs` (เมนูแท็บ) · `audio.rs` · `rpg.rs` (สเตตัส ตีบวก ลูต ผู้ติดตาม เควสต์ สภาพอากาศ) · `dungeon.rs` (ดันเจี้ยนห้อง + ถ้ำ) · `farm.rs` (ฟาร์ม เตียง Grid Snap) · `assets.rs` (จุดแทนที่ asset)


- **World**: สร้างภูมิประเทศด้วย value-noise (fbm) แบ่ง chunk 32×32 แคชไว้ · วัตถุ (ต้นไม้ หิน หีบ ฯลฯ) สร้างแบบ deterministic จาก seed จึงไม่ต้องเก็บทั้งโลก เก็บเฉพาะสิ่งที่ผู้เล่นเปลี่ยน (`removed`, `placed`, `tmod`) · แคมป์พ่อค้าสุ่มจาก seed ต่อเซลล์ 64×64 ไทล์ (จึงไม่ต้องเก็บ เซฟเก็บแค่ว่าค้นพบแล้วหรือยัง) · ไฟล์เซฟเป็นข้อความ รองรับเซฟ v1 เดิม

## v6 part 2 — สกินตัวละคร
- ตัวละครแยก 3 ชิ้น (หัว/ตัว/ขา) มี 7 รูปแบบต่อชิ้น: พื้นฐาน · เกราะ 4 ระดับ (หิน/อัญมณี/ราชา/ดาวตก) · ชุดชาวไร่ · ชุดนักล่า — เกราะมาก่อนชุดในแต่ละช่อง (หมวกเกราะ+เสื้อชาวไร่ ผสมได้)
- ครบชุดเกราะดาวตก 3 ชิ้น = ออร่าม่วง + ประกายโคจร
- ชุดชาวไร่ (ไม้ 4 + ข้าวโพด 3) / ชุดนักล่า (ไม้ 3 + เนื้อ 3 + สมุนไพร 2) คราฟต์ในเมนูคราฟต์ สลับได้ที่แท็บ ชุด/ของ (มีพรีวิวตัวละคร)
- debug build: F12 วนสกินทดสอบ

## v6 part 3 — NPC, ครอบครัว, หมู่บ้าน/อาณาจักร
- **คนหลงทาง**: สุ่มจาก seed ต่อเซลล์ (~22% ของเซลล์) มีเครื่องหมาย ! เหนือหัว ได้ยินเสียงเรียกเมื่อเข้าใกล้ — กด Q / ปุ่ม "ใช้" เพื่อช่วย แล้วเขาจะเดินตาม
- **ชวนมาอยู่ฐาน**: เมนู → แท็บ "ชุมชน" → คุย/จัดการ → ชวน (ต้องมีเตียงว่าง 1 เตียงต่อ 1 คน) · เตียงสร้างได้ในเมนูสร้าง
- **อยู่ต่อหรือไป**: ทุกรุ่งเช้า ชาวบ้านกินอาหารจากกล่องเก็บของในรัศมี 16 ช่องจากเตียง · เตียงยังอยู่ +3 / หายไป −25 · ได้กิน +5 / หิว −20 · ความสุข 0 = ย้ายออก
- **ระดับ**: 1–3 คน ค่าย (ชาวไร่รดน้ำ/เก็บเกี่ยวให้) · 4–10 คน หมู่บ้าน (พ่อค้าเฉพาะทาง + ทหารยามฟันมอนใกล้บ้าน) · >10 คน + ปราสาท + กำแพงเมือง 12 ชิ้น = อาณาจักร (เก็บภาษีทุกเช้า)
- **ความสัมพันธ์**: คุยวันละครั้ง (+1 สนิท) · ของขวัญวันละครั้ง · สนิท 8/10 + ความสุข ≥50 + 100 เหรียญ + 5 อัญมณี = แต่งงาน (ได้คนเดียว) · หลังแต่ง 3 วัน มีเตียงว่างจะมีลูก (สูงสุด 2)
- เซฟ: บรรทัด `town` / `npc` / `npcseen` (เซฟเก่าโหลดได้ ไม่มีชาวบ้าน)
- debug build: **Home** วาร์ปไปคนหลงทางที่ใกล้สุด · **End** สร้างหมู่บ้านทดสอบ (เตียง+อาหาร+ชาวบ้าน 4 คน)
- ยังไม่ได้ทดสอบ: ความสมดุลของอาหาร/ภาษีในการเล่นยาวๆ, การเดินของชาวบ้านชนสิ่งกีดขวางซับซ้อน, สัมผัสบนมือถือจริง

## v7a — สังคมสมจริง
- **นิสัย 5 แบบต่อคน** (ใจดี/ใจร้อน/โลภ/กล้าหาญ/ช่างพูด — แต่ละแบบมีด้านตรงข้าม เช่น เย็นชา ใจเย็น ขี้ขลาด ขี้อาย) + **ของที่ชอบ 1 อย่าง ของที่เกลียด 1 อย่าง** — ยิ่งสนิทยิ่งรู้จักมากขึ้น (สนิท 4+ รู้ของโปรด, 6+ รู้ของที่เกลียด)
- **โกรธ vs แค้น**: โกรธ = ระยะสั้น หายใน 1–3 วัน · แค้น = ฝังใจ จางช้า (คนใจดีให้อภัยเร็วกว่า) · ความรู้สึกต่อคุณ = สนิท×10 − แค้น − โกรธ/2 (ไม่ชอบ → เฉย → คุ้นเคย → เพื่อน → สนิท → คนสำคัญ)
- สิ่งที่ทำให้โกรธ/แค้น: ฟันโดนชาวบ้าน (เฉพาะตอนไม่โดนมอนสเตอร์) · ให้ของที่เขาเกลียด · ปล่อยให้หิว/ไม่มีเตียง (คนใจร้อนแค้นเร็วกว่า) · ไล่เพื่อนของเขาออก · แต่งงานโดยที่เขาสนิทกับคุณมาก (คนไม่ใจดีจะอิจฉา คนใจดียอมรับ คนสนิทปานกลางยินดีด้วย)
- ผลจริง: คนโกรธไม่ยอมคุย/รับของ · พ่อค้าเลิกขายให้ถ้าไม่ชอบหน้า (เพื่อนสนิทได้ราคาลด คนแปลกหน้าแพงกว่า) · ยาม/ชาวไร่หยุดงานถ้าเกลียดผู้นำ · แต่งงานไม่ได้ถ้ายังมีเรื่องค้างคาใจ · ไอคอนกากบาทแดงเหนือหัวเมื่อโกรธ
- แก้ได้: **ขอโทษ** (วันละครั้ง โอกาสสำเร็จขึ้นกับความใจดีและความสนิท) · **ของขวัญตรงใจ** · ให้เวลา · ของขวัญซ้ำ ๆ จะเบื่อ ได้ผลน้อยลง
- ความสัมพันธ์ **ระหว่างชาวบ้านกันเอง** (คำนวณจากนิสัยที่เข้ากัน/ไม่เข้ากัน): ทะเลาะ · นั่งคุยจนสนิท · ง้อคืนดี · ถ้าเกลียดกันมากคนที่กล้า/เข้าสังคมน้อยกว่าย้ายออก — เหตุการณ์ทั้งหมดขึ้น "ข่าวหมู่บ้าน" ในแท็บชุมชน
- ไม่คุยนานเกิน 6 วัน สนิทลดลง (คู่สมรสที่ถูกทิ้งไว้จะเศร้า) · แบ่งงานตามความถนัด (กล้าสุด = ยาม, โลภ+ช่างพูด = พ่อค้า, ที่เหลือทำไร่) · ชื่อ 36 ชื่อ ไม่ซ้ำในหมู่บ้านเดียวกัน
- เซฟ: บรรทัด `nsoc` / `nrel` / `nnews` (เซฟเก่าโหลดได้ นิสัยสร้างจาก id เหมือนเดิม)
- ยังไม่มี: ชาวบ้านฆ่า/ถูกฆ่าได้, ความรักระหว่างชาวบ้านกันเอง, การนินทา — ความหิว/กระหายของผู้เล่นและ NPC อยู่ใน v7b

## v7b — หิว / กระหายน้ำ / เหนื่อย
- **3 แถบใต้ XP**: อิ่ม · น้ำ · แรง (0–100) · ค่าต่ำกว่า 15 กะพริบแดง + ข้อความสถานะ (กระหายน้ำมาก/หิว/ท้องเสีย/เพลีย) · ปิด/เปิดได้ในตั้งค่า "เอาตัวรอด": ปิด / ปกติ (เลือดไม่ต่ำกว่า 1) / ยาก (หมดสติได้)
- **อัตราสิ้นเปลือง** (1 วันเกม = 4 นาทีจริง): น้ำหมดใน ~1.5 วัน · อาหารหมดใน ~3 วัน · แรงหมดใน ~4 วัน · เดิน/ต่อสู้เปลืองขึ้น · ทะเลทรายกระหายเร็ว ×2.2 · หิมะหิวเร็ว ×1.5 (ผิงไฟใกล้ ๆ หายหนาว) · ฝนช่วยดับกระหาย
- **ผลต่อร่างกาย**: ต่ำกว่า 30/15/0 → เดินช้าลง (−5% / −15% / −30%) · หิว/กระหาย/ป่วย = ไม่ฟื้นเลือดเอง · หมดน้ำหรือหมดอาหารเลือดลดทีละ 1 ทุก ~8 วิ (หมดทั้งคู่เร็วขึ้น 2 เท่า)
- **กิน**: ผลไม้/ข้าวโพด/แครอทไม่เสี่ยง · **ของดิบเสี่ยงท้องเสีย** (ปลา 20% เนื้อ 30% เห็ด 25%) → เดินช้า หิวเร็ว ไม่ฟื้นเลือด 60 วิ · **สมุนไพรแก้ท้องเสีย** · อาหารปรุงอิ่มมากกว่าและปลอดภัย (สตูว์ +60) · ปุ่มกินของดิบอยู่ในแท็บชุดของ
- **น้ำ**: บ่อน้ำ (สร้างได้ สะอาด +45) · น้ำจืดตามบึง/ทะเลสาบ +30 (เสี่ยงท้องเสีย 10%) · **น้ำทะเลเค็ม** (น้ำตื้นที่ติดทะเลลึกภายใน 3 ช่อง) ดื่มแล้วยิ่งกระหาย
- **นอน**: นอนข้ามคืนฟื้นแรงเต็ม หายท้องเสีย ใช้น้ำ/อาหารแค่ครึ่งอัตรา และไม่ตายตอนหลับ
- **ชาวบ้าน**: ตื่นเช้ามองหาแหล่งน้ำจืด/บ่อภายใน 20 ช่อง ไม่มี = ความสุข −15 + ข่าว "ไม่มีน้ำดื่ม" · ไม่ต้องอยู่ริมน้ำถ้ามีบ่อ · เลือกกินของโปรดก่อน ไม่ชอบของที่เกลียด (ยอมกินถ้าไม่มีอย่างอื่น แต่หงุดหงิด)
- เซฟ: บรรทัด `need` (เซฟเก่าเริ่มที่เต็ม 100)
- **ยังไม่ทำ / ข้อจำกัด**: ชาวบ้านไม่ตายเพราะอด · ไม่มีต้มน้ำ/ขวดน้ำพกพา · ตัวเลขอัตราสิ้นเปลืองตั้งตามความสนุกของเกม ไม่ใช่ค่าจริงทางสรีรวิทยา · ยังไม่ได้ลองบาลานซ์บนมือถือจริง (ถ้าหนัก/เบาไปปรับที่ `HUNGER_RATE` / `THIRST_RATE` ใน `needs.rs`)

## v7d — ต้นไม้หลากหลายตามไบโอม
- **ต้นไม้ 9 ชนิดใหม่ + โอ๊ก/สนหิมะเดิม**: โอ๊ก · เบิร์ช (ลำต้นขาวมีรอยดำ) · แอปเปิล · มะพร้าว · สปรูซ · เมเปิล (ใบส้มแดง) · โอ๊กเก่าแก่ (ใหญ่ ไม้ได้ 5–7) · ต้นกล้า (ไม้ 1) · ต้นไม้ตาย
- **ขึ้นตามพื้นที่จริง**: ทุ่งหญ้า = โอ๊ก เบิร์ช แอปเปิล(หายาก) เมเปิล ต้นกล้า โอ๊กเก่าแก่ · ป่าทึบ = สปรูซมากสุด + โอ๊ก เบิร์ช เมเปิล โอ๊กเก่าแก่ · ชายหาด = มะพร้าว · ทะเลทราย = กระบองเพชร ต้นไม้ตาย และ **มะพร้าวเฉพาะรอบน้ำ (โอเอซิส)** · เขตหินผา = สปรูซ/ต้นไม้ตาย · หิมะ = สนหิมะ สปรูซ ต้นไม้ตาย
- **เก็บผลโดยไม่ต้องโค่น**: แอปเปิล (ปุ่ม "ใช้" → ได้ผลไม้ 2–4 ผล) · มะพร้าว (ดื่มน้ำมะพร้าว น้ำ +28 อิ่ม +6 — น้ำสะอาด ไม่เค็ม ไม่ท้องเสีย) · ต้นจะออกผลใหม่ใน 2 วันเกม (ตอนยังไม่สุกต้นจะไม่มีผลให้เห็นและปุ่ม "ใช้" ไม่ขึ้น) · โค่นต้นที่ยังมีผลได้ทั้งไม้และผลไม้
- ขนาดต้นต่างกันตามชนิด: ตีกี่ครั้งและได้ไม้เท่าไหร่ (ต้นกล้า 1 ครั้ง · โอ๊กเก่าแก่ 6 ครั้ง)
- เปลี่ยนชื่อไอเทม "เบอร์รี่" → "ผลไม้" (รวมเบอร์รี่ป่ากับแอปเปิล · ไอเทมเดียวกัน กินแล้ว +12 อิ่ม +3 HP)
- เซฟ: บรรทัด `fruit` (ต้นที่เก็บผลไปแล้ว + วันที่เก็บ · เซฟเก่าโหลดได้ ต้นทุกต้นมีผลเต็ม) · ต้นไม้ในโลกสร้างจาก seed เหมือนเดิม จึงไม่มีการเปลี่ยนแปลงตำแหน่งต้นไม้เดิม ยกเว้นชนิดที่สุ่มใหม่: **ต้นไม้ในโลกเดิมจะเปลี่ยนชนิดบางต้น** (ตำแหน่งเดิม ชนิดใหม่)
- **ยังไม่ทำ / ข้อจำกัด**: ต้นไม้ที่โค่นแล้วไม่งอกใหม่ · ไม่มีการปลูกต้นกล้าให้โตเป็นต้นไม้ · ไม่มีฤดูกาล (ใบเมเปิลเป็นสีส้มตลอด) · ผลไม้ใช้ไอเทมเดียวกับเบอร์รี่ (ไม่มีแอปเปิลแยก) · ต้นไม้ในถ้ำ/ดันเจี้ยนไม่เปลี่ยน

## v8b — โลกมีอะไรให้ค้นพบ
- **ไบโอมใหม่**: หนองน้ำ (เดินช้า 30% · ต้นไม้หนองน้ำ ต้นกก เห็ดเก็บได้) · สะวันนา (ต้นอะคาเซีย หญ้าแห้ง · กระหายเร็ว ×1.6) · **ภูเขาไฟ** (ปล่องลาวา + ขอบปล่องหิน + ธารลาวาไหลลงด้านหนึ่ง + ทุ่งเถ้า · หินออบซิเดียนให้อัญมณี · เถ้าร้อนกระหายเร็ว ×2.6 · ยืนติดลาวาโดนเผา -1 และกระเด็นออก)
- **จุดสำคัญ** (สุ่มจาก seed · ค้นพบได้ XP + แสดงบนแผนที่ใหญ่): ซากปรักหักพังโบราณ (กำแพงพัง เสาหิน กระดูก · ผู้พิทักษ์โครงกระดูกตื่นตอนค้นพบ · หีบโบราณ 20–40 เหรียญ อัญมณี 2–4 ยา และอาจได้เศษดาว) · วงหินศักดิ์สิทธิ์ (แท่นบูชา: ขอพรวันละครั้ง เลือดเต็ม หายป่วย หายเพลีย) · ต้นไม้ยักษ์โบราณ (ในป่า: เก็บสมุนไพร + ผลไม้วันละครั้ง) · ภูเขาไฟ
- **หมู่บ้านหลายแบบ**: แคมป์พ่อค้าเปลี่ยนตามที่ตั้ง — ริมน้ำ/หนองน้ำ = หมู่บ้านชาวประมง (บ้านไม้หลังคาฟาง ราวตากปลา · ขายปลา/ซุปปลา) · ทะเลทราย/สะวันนา = กองคาราวาน (บ้านดิน ไหน้ำ · ขายเนื้อแห้ง/สมุนไพร) · หิมะ = กระท่อมนายพราน (บ้านซุงหลังคาหิมะ กองฟืน · ขายเนื้อ/ลูกธนูราคาส่ง) · ที่อื่นยังเป็นเต็นท์พ่อค้าเร่เดิม
- **ถ้ำพิเศษ**: ปากถ้ำในหิมะ = ถ้ำคริสตัล (แร่มากขึ้น + คริสตัลเรืองแสง ตีได้อัญมณี 2) · ปากถ้ำในทุ่งเถ้า = ถ้ำลาวา (ลาวาตามผนัง มอนสเตอร์ดุขึ้น ×1.25)
- เซฟ: บรรทัด `marks` (จุดสำคัญที่ค้นพบ) และ `bless` (วันที่ขอพร/เก็บของล่าสุด) · **โลกเดิมจะเปลี่ยนบางส่วน**: ทุ่งหญ้าบางส่วนกลายเป็นหนองน้ำ/สะวันนา และภูเขาสูงบางจุดกลายเป็นภูเขาไฟ (ของที่วางไว้ยังอยู่ที่เดิม)
- **ยังไม่ทำ / ข้อจำกัด**: หมู่บ้านธรรมชาติมีแค่พ่อค้า (ชาวบ้านจริงยังต้องพามาเองที่ฐาน) · บ้านในหมู่บ้านเข้าไม่ได้ · ภูเขาไฟไม่ระเบิด · ถ้ำคริสตัล/ลาวาใช้บอสเดิม

## v8c — ฤดูกาล + ต้นไม้งอกใหม่ + ปลูกต้นไม้
- **4 ฤดู ฤดูละ 5 วันเกม** (เริ่มเกมที่ฤดูร้อน → ใบไม้ร่วง → หนาว → ใบไม้ผลิ) · แสดงชื่อฤดูบน HUD · แจ้งเตือนตอนเปลี่ยนฤดู
- ร้อน: กระหายเร็ว ×1.15 ฝนน้อย · ใบไม้ร่วง: ใบไม้ผลัดใบเป็นสีส้ม/เหลือง พื้นหญ้าเหลือง ฝนบ่อย · **หนาว**: หญ้า/ป่า/หินผา/หนองน้ำมีหิมะคลุม ต้นไม้ผลัดใบเหลือแต่กิ่ง (สน/สปรูซยังเขียว) ดอกไม้หาย ฝนกลายเป็นหิมะ (เดินช้า) หิวเร็ว ×1.2 (ยกเว้นข้างกองไฟ) พุ่มไม้แทบไม่มีผล · ใบไม้ผลิ: ฝนบ่อย พืชผลโตเร็ว ×1.3
- พืชผลในแปลง: ร้อน ×1 · ใบไม้ร่วง ×0.8 · หนาว ×0.25 · ใบไม้ผลิ ×1.3
- **แอปเปิลออกผลเฉพาะฤดูร้อน/ใบไม้ร่วง** · มะพร้าวออกตลอดปี
- **ต้นไม้ธรรมชาติที่โค่นแล้วงอกใหม่**: 3 วัน → ต้นกล้า → อีก 3 วัน → ต้นชนิดเดิม (ฤดูหนาวไม่นับวัน · ไม่งอกในระยะ 3 ช่องจากสิ่งก่อสร้าง/แปลงปลูก จะได้ไม่ขึ้นทับฐาน) · ตัดต้นกล้าที่กำลังงอกจะเริ่มนับใหม่ · เซฟเก่า: ต้นที่เคยโค่นไว้จะเริ่มงอกด้วย
- **ปลูกต้นไม้เอง**: เมนูสร้าง → "ปลูกต้นกล้า" (ไม้ 1 + ผลไม้ 1) · ปลูกบนหญ้า/ป่า/หาด/หินผา/หิมะ/หนองน้ำ/สะวันนาได้ · 4 วันโตเป็นต้นไม้ตามพื้น (หาด = มะพร้าว · สะวันนา = อะคาเซีย · หนองน้ำ = ต้นไม้หนองน้ำ) · ต้นที่ปลูกเองตัดแล้วไม่งอกเอง
- เซฟ: บรรทัด `felled` และ `planted`
- **ยังไม่ทำ / ข้อจำกัด**: ความยาวกลางวัน/กลางคืนเท่ากันทุกฤดู · ชาวบ้านยังไม่ปรับตัวตามฤดู (ไม่สะสมอาหารหน้าหนาว) · ทะเลสาบ/แม่น้ำไม่กลายเป็นน้ำแข็ง · ต้นกล้าในเมนูใช้ไอคอนไม้

## v8d — สัตว์ป่า
- **เหยื่อ**: กวาง (ป่า/ทุ่งหญ้า) · กระต่าย (ทุ่งหญ้า/สะวันนา/หิมะ · หน้าหนาวขนขาว) · แอนทิโลป (สะวันนา) — เดินเล่น/กินหญ้า เห็นผู้เล่นหรือหมาป่าแล้ววิ่งหนี (เร็วกว่าคน) · แต่ละตัวกล้าไม่เท่ากัน

## v8e — คำขอและปัญหาจากชาวบ้าน
- ชาวบ้านมี **เรื่องขอให้ช่วย** ตามนิสัย/ความต้องการจริง (เกิดตอนรุ่งเช้า · กรอบคำพูดสีเหลืองเหนือหัว · รายการรวมอยู่ในแท็บชุมชน · มีเวลา 3 วัน):
  - **ขอของกิน**: คนที่ไม่มีความสุข/หิว ขอของที่เขาชอบกิน · **คนโลภ** อยากได้อัญมณี (จ่ายเหรียญให้)
  - **ล่าสัตว์**: คนขี้ขลาดขอให้กำจัดหมาป่า/หมูป่า/จระเข้ (นับเฉพาะที่ล่าหลังรับคำขอ)
  - **ฝากของ**: คนช่างพูดฝากของที่เพื่อนสนิทชอบไปให้ (ใช้ของของคุณ) → สองคนสนิทกันขึ้น
  - **ไกล่เกลี่ย**: คนใจดีขอให้ช่วยสองคนที่ทะเลาะกัน → คุยกับทั้งคู่ในวันเดียวกัน
  - **ข้อพิพาท** (สองคนเกลียดกันมาก): เข้าข้างใคร อีกฝ่ายแค้นและโกรธคุณ · คนอื่นในหมู่บ้านพอใจ/ไม่พอใจตามว่าสนิทกับใคร · หรือให้ประนีประนอม (ได้ผลเฉพาะถ้าสนิทกับทั้งคู่ระดับ 5 ขึ้นไป ไม่งั้นทั้งคู่โกรธ)
  - **ขโมย**: คนโลภ+ใจดำที่ไม่มีความสุขแอบเอาเหรียญ/อัญมณีจากกล่องเก็บของ คนช่างพูดเห็นแล้วมาบอก → **ทวงคืน** (ได้ของคืน คนขโมยโกรธ) · **ยกโทษ** (เขาสำนึก ความโลภลดลง แต่พยานไม่พอใจ) · **ไล่ออก** (ได้ของคืน เพื่อนของเขาเสียใจ)
- รางวัลขึ้นกับนิสัยคนขอ: คนใจดีให้มาก คนโลภให้น้อย · สำเร็จแล้วสนิทขึ้น หายโกรธ
- ไม่ช่วยจนหมดเวลา = ผิดหวัง (ความสุขลด คนใจร้อนโกรธ) · ปฏิเสธตรงๆ ผิดหวังน้อยกว่า
- เซฟ: บรรทัด `nreq`
- **ยังไม่ทำ / ข้อจำกัด**: คำขอมีพร้อมกันสูงสุด 4 เรื่อง · ไม่มีเควสต์หลายขั้น/เนื้อเรื่องหลัก · คนขโมยไม่ขโมยจากตัวผู้เล่น · ชาวบ้านที่หลงทางยังไม่ขออะไร
